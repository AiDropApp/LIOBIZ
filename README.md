## Run locally

```bash
pnpm install
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Recapture screenshots

With the dev server running:

```bash
pnpm run screenshots
```

## Stack

- Next.js 15
- React 19
- Tailwind CSS
- Drizzle ORM + SQLite
